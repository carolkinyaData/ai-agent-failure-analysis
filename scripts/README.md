# Scripts Folder

This folder contains standalone Python scripts used for preprocessing, anomaly detection, and feature importance analysis.

## Files

**preprocess.py**  
Handles data cleaning, type conversion, and preparation steps.

**anomaly_detection.py**  
Applies Isolation Forest, One-Class SVM, and statistical outlier detection.

**feature_importance.py**  
Computes feature importances using Random Forest, permutation importance, and SHAP values.
